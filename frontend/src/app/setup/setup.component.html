Welcome to Trailarr

Trailarr downloads trailers for the movies and series you already have, and keeps them next to your media so Plex, Emby and Jellyfin show them.

  • It reads your library from Radarr, Sonarr or Plex. It never changes anything there.
  • Profiles decide what to download — quality, format, and which media each one covers. Two are ready to use.
  • Nothing downloads until you say so. This guide ends by showing you what the first run would do.

This takes about two minutes. You can leave at any point and finish later — anything you set up is kept.
